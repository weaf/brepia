## Goal

Add STEP as pCAD's 3D CAD interchange format while leaving existing STL and DXF behavior unchanged. STEP should preserve native B-Rep/analytic geometry where the converter supports it and warn when a construct requires mesh fallback.

## Known boundary

STEP V1 sends only the complete SCAD source into the sandbox. Custom relative project files and `import()` mesh/assets are not transferred. Do not widen the sandbox to arbitrary host paths to support these; multi-file/asset support needs an explicit normalized workspace input design.

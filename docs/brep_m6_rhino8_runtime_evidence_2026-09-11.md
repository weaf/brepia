## Accepted transform contract

Canonical transform semantics remain:

```text
rotateDeg = [rx, ry, rz]
R = Rx * Ry * Rz
p' = R * p + T
```

The rotation is intrinsic XYZ around the canonical local origin, followed by translation. Positive angles follow the right-hand convention.

The Rhino compiler implements the same semantics with origin-centered RhinoCommon rotations and:

```text
Rotation  = RotationX * RotationY * RotationZ
Transform = Translation * Rotation
```

Result cardinality remains `single`, so the Grasshopper Result output remains Item Access.

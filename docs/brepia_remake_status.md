## Prompt-profile migration — intentionally last

`src/components/settings/PromptProfilesSettings.tsx` still exposes `CADAM Original`.

This is not a blind display-string replacement. The built-in profile participates in:

- overlay behavior relative to the built-in prompt;
- base revision/fingerprint tracking;
- fork lineage;
- stale-fork warnings;
- built-in API/profile semantics.

At the end of the remake, inspect the actual built-in prompt and decide whether to:

1. preserve it as an explicitly inherited/upstream profile;
2. rename only its display identity; or
3. introduce a genuine Brepia built-in prompt revision and migrate displayed lineage accordingly.

Internal IDs need not change solely because the display label changes.

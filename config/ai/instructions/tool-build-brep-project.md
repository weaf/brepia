Native primitive coordinate semantics are centered-origin semantics. A `box` is centered on its local origin, so width W and depth D occupy X = -W/2..W/2 and Y = -D/2..D/2. A `cylinder` is likewise centered on its local origin. `transform.translate` is a displacement from that centered local origin; it is not an absolute coordinate measured from a box minimum corner. Therefore a concentric/centered cylindrical through-hole in a centered box normally uses the same local origin (for example translate `[0, 0, 0]`), not `[W/2, D/2, 0]`.

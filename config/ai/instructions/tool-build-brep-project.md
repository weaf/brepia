Native primitive coordinate semantics are centered-origin semantics. A `box` is centered on its local origin, so width W and depth D occupy X = -W/2..W/2 and Y = -D/2..D/2. A `cylinder` is likewise centered on its local origin. `transform.translate` is a displacement from that centered local origin; it is not an absolute coordinate measured from a box minimum corner. Therefore a concentric/centered cylindrical through-hole in a centered box normally uses the same local origin (for example translate `[0, 0, 0]`), not `[W/2, D/2, 0]`. `linearPattern` is the bounded multi-instance composition node. It references exactly one existing single-shape `input`, uses `axis: "x" | "y" | "z"`, a literal integer `count` from 2 through 32, and a non-zero millimetre-compatible `spacing` scalar. `spacing` may be a literal, published-parameter reference or bounded M1 scalar expression. Instance index 0 is the unshifted input; later instances are translated by `index * spacing` along the selected axis, preserving canonical index order. A linear pattern returns an `instanceSet`, not one fused solid. It may be the primary `resultNodeId`, in which case Brepia and Grasshopper expose all instances as separate ordered bodies/Breps. It may also be used as a `subtract.tools[]` entry; subtraction then applies every pattern instance as an ordered cutter. `mirror` is a single-shape symmetry node. It references exactly one existing `input`, returns only the mirrored shape, and never implicitly keeps or unions the original. `normalAxis: "x"` means a YZ mirror plane, `"y"` means XZ and `"z"` means XY. `offset` is the mirror-plane position in millimetres along that normal axis and may be a literal, parameter reference or bounded M1 scalar expression. Use `mirror` when the requested result is the reflected counterpart of a shape. If the user wants both the original and mirrored copy, model those as two explicit branches and combine them only with a supported operation whose semantics are actually correct; do not treat `mirror` itself as a two-instance pattern or collection.
